# I Watched Kamoki Go Underwater

A single-page Next.js story built for AI Seekho Assignment 4 — a firsthand
account of the July 2026 Gujranwala/Kamoki floods, backed by verified data,
explaining why the flooding keeps happening, and pitching four practical,
buildable solutions. Ends with a "Join the Movement" form (name, email,
phone) that simulates a submission in memory — no backend, no database, as
per the assignment brief.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push this repo to GitHub, then import it on [Vercel](https://vercel.com) —
no environment variables or extra config needed.
